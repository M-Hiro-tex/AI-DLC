プロジェクト一覧表示（D5.1）の検索機能として、以下のどれを実装しますか？

A) 名前での部分一致検索のみ
B) 名前での部分一致検索 + タグ/カテゴリでのフィルタリング
C) 名前での部分一致検索 + ステータスでのフィルタリング + タグ/カテゴリでのフィルタリング
D) すべての検索機能（名前、説明文、ステータス、日時範囲、タグ/カテゴリ）

### Q12の明確化

**元の回答**: E. 最適な方法で。

**問題点**: 「最適な方法」が具体的に何を指すのか不明確です。プロジェクト作成時にどのようなデフォルト値を設定するのか、明確な仕様が必要です。

**追加質問 Q12-1: プロジェクト作成時のデフォルト値の詳細**

プロジェクト作成時に自動設定する内容を具体的に指定してください。以下のどれが「最適」だと考えますか？

A) ステータス: Draft、進捗率: 0%、作成日時、更新日時のみ（シンプル）
B) 上記 + 初期仕様の自動作成（空の仕様ドキュメントを自動生成）
C) 上記 + サンプルプロジェクトを選択した場合のみ、サンプルコンテンツを自動追加
D) ステータス: Draft、進捗率: 0%、作成日時、更新日時のみ（初期仕様は手動作成）
E) その他（[Answer]タグの後に具体的に記述してください）

[Answer]: C

**補足説明**:
- **選択肢A/D**: 最小限のデフォルト値のみ設定し、仕様は後からユーザーが手動で作成
- **選択肢B**: 新規プロジェクト作成時、常に空の仕様ドキュメントを自動作成（すぐに編集開始可能）
- **選択肢C**: 通常プロジェクトは空、サンプルプロジェクトの場合のみコンテンツをプリロード
